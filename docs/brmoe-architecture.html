BR-MoE Architecture

Bi-Level 混合精度量化 + 低秩补偿的 MoE 压缩框架 — 离线 ILP 配置搜索 / 量化与补偿核心 / 多后端推理 / 评测

① 离线：ILP 全局配置搜索

  • • collect_expert.py 用 forward hook 缓存 FP16 参考输出，逐专家逐 (bit, rank) 量化测 L2 误差
  • • 代理指标无需全模型重训，可快速评估上千种配置
  • • ILP_solver/solver.py 用 OR-Tools SCIP 解 MCKP：每专家唯一配置 + 总内存 ≤ budget
  • • 输出 best_config.json，直接作为压缩脚本的输入

② 量化 + 低秩补偿（位宽-秩耦合）

  • • BRMoELinear.compress()：分组量化 + 近端优化 scale/zero，再用 SVD 低秩矩阵补偿残差
  • • 补偿器同样 int3 量化，避免低秩补偿带来显存回涨
  • • BitPack 3bit_32：32-bit 承载 10 个权重
  • • 核心洞察：最优补偿 rank 依赖位宽，二者必须联合优化

③ 推理后端与评测

  • • 推理可选 PyTorch 参考实现 / BRMoE int3 CUDA (sm_80) / Marlin 4-bit / Triton int3
  • • Triton 版免编译，T4 上比逐专家循环快 1.7–4.4×
  • • 支持 Mixtral-8×7B、DeepSeek-V2-Lite、Qwen1.5-MoE、Qwen3-MoE
  • • 评测：WikiText-2 PPL / HellaSwag / PIQA / MMLU（内嵌 lm-evaluation-harness）
